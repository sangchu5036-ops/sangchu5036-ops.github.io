8. Gauss–Markov 이론 증명

OLS 추정량: β̂ = (X'X)⁻¹X'Y 모형: Y = Xβ + u 대입: β̂ = (X'X)⁻¹X'(Xβ + u) = β + (X'X)⁻¹X'u 조건부 기대값: E[β̂ | X] = β + (X'X)⁻¹X'E[u | X] Gauss–Markov 가정에서 E[u | X] = 0 이므로 E[β̂ | X] = β 따라서 OLS는 불편추정량입니다. ──────────────────────────── 또한 Var(u | X) = σ²I 이면 Var(β̂ | X) = σ²(X'X)⁻¹ 이제 임의의 다른 선형 불편추정량을 β̃ = AY 라고 합시다. 불편추정량이므로 AX = I OLS 행렬을 A₀ = (X'X)⁻¹X' 라고 하면 A = A₀ + C 로 쓸 수 있고 CX = 0 이어야 합니다. 따라서 Var(β̃ | X) − Var(β̂ | X) = σ²CC' 그리고 임의의 벡터 a에 대하여 a'CC'a = (C'a)'(C'a) ≥ 0 따라서 σ²CC'는 positive semidefinite입니다. 즉 모든 선형 불편추정량 β̃에 대해 Var(β̃ | X) − Var(β̂ | X) 가 positive semidefinite입니다. 결론: OLS는 Gauss–Markov 가정 아래에서 Best Linear Unbiased Estimator 즉 BLUE입니다.

β̂₀ OLS가 추정한 절편입니다. X=0일 때 Y의 예측값입니다. 회귀선의 위치를 결정합니다.
β̂₁ OLS가 추정한 기울기입니다. X가 1단위 변할 때 Y의 예측값이 얼마나 변하는지 봅니다.
Fitted Value 회귀식이 각 X에 대해 예측한 Ŷ 값입니다. 실제 Y와 비교하여 잔차를 계산합니다.
Residual eᵢ = Yᵢ − Ŷᵢ 입니다. 회귀식이 설명하지 못한 부분입니다.
SSE Σ(Yᵢ − Ŷᵢ)², 즉 잔차제곱합입니다. OLS가 직접 최소화하는 값입니다.
SST Σ(Yᵢ − Ȳ)², Y의 전체 변동입니다. 회귀분석 이전에 존재하는 전체 Y 변동의 크기를 나타냅니다.
SSR Σ(Ŷᵢ − Ȳ)², 회귀식이 설명한 변동입니다. 전체 변동 중 회귀식이 설명한 부분을 나타냅니다.
R² 1 − SSE/SST 입니다. Y의 전체 표본 변동 중 회귀식이 설명한 비율을 보여줍니다. OLS 계수를 구하는 데 반드시 필요한 값은 아닙니다.
Adjusted R² 설명변수 수와 표본크기를 고려하여 R²를 보정한 값입니다. 다중회귀에서 변수를 무작정 추가하면 R²가 올라가는 문제를 보완합니다. 단순회귀에서는 중요성이 상대적으로 작습니다.
MSE SSE/(n−2) 입니다. 단순회귀의 Gauss–Markov 가정 아래 σ²의 불편추정량입니다.
Standard Error β̂의 표본추출분포의 표준편차를 추정한 값입니다. 추정된 계수가 얼마나 불확실한지를 평가합니다.
t statistic β̂ / SE(β̂)입니다. 보통 H₀: β=0을 검정할 때 사용합니다.
p-value 귀무가설이 참이라는 전제하에서 지금과 같거나 더 극단적인 통계량이 관측될 확률입니다. 회귀계수 또는 회귀식에 대한 가설검정에서 사용합니다.
95% CI 추정량의 95% 신뢰구간입니다. 하나의 점추정값만 보지 않고 추정의 불확실성 범위를 봅니다.
F statistic 설명된 변동과 설명되지 않은 변동의 상대적 크기를 이용하는 검정통계량입니다. 회귀식 전체가 설명력을 가지는지 검정합니다. 단순회귀에서는 기울기 t통계량의 제곱과 같습니다.
Q-Q Plot 잔차 분위수와 정규분포의 이론적 분위수를 비교합니다. 잔차의 정규성을 시각적으로 확인합니다. 정규성은 BLUE의 필요조건은 아닙니다.
Unbiased E[β̂ | X] = β를 의미합니다. 반복표본에서 추정량의 평균이 참 모수와 일치하는지를 뜻합니다.
BLUE Best Linear Unbiased Estimator입니다. 모든 선형 불편추정량 중 OLS가 최소 분산을 가진다는 Gauss–Markov 정리의 결론입니다.
